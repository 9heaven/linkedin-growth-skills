# Comment Moves

Six ways a comment can add something. Shapes, not scripts: fill them with the user's
own take and experience.

## 1. Add an example

```
[What you saw in your own work, with one concrete detail.] [What it changed or
showed.] [How it bears on the author's point, if that is not obvious.]
```

## 2. Extend

```
The part I'd add: [a distinct point the post did not make]. [Why it matters for
the people reading.]
```

## 3. Qualify or disagree

```
[What the post gets right, in a clause], but [where it breaks, specifically].
[What you do instead, or what you have seen happen.]
```

## 4. Ask

```
[A specific question the author can answer and other readers want answered.]
[Why you are asking, in a clause.]
```

Never "Thoughts?" or "Can you say more?". The question must show you read the post.

## 5. Translate for a niche

```
For [your audience], this shows up as [the specific version of the problem].
[The one thing that changes because of it.]
```

## 6. Add a number

```
[A figure from your own work that supports or complicates the post.] [What you
take from it.]
```

Only a figure the user gave. Otherwise use move 1 with a placeholder.

## Which move for which author

| Author is | Best moves | Why |
|---|---|---|
| A buyer | Add an example, Ask | Be useful on their terms. Never pitch under a buyer's post. |
| A peer | Extend, Qualify or disagree | Peers reward a real second opinion, and their audience overlaps with the user's. |
| An adjacent expert | Ask, Translate for a niche | It starts a relationship and shows where the two fields meet. |
| A large account | Translate for a niche, Extend | The comment is read by their audience, so be early and be specific. |

## Signs of a generated comment (remove them)

- Opens with the author's name and a compliment.
- Restates the post in different words before saying anything.
- "This resonates", "So true", "Couldn't agree more".
- A tidy list of three.
- Ends with a generic question to the room.
- Exclamation marks and emoji doing the work of a point.
