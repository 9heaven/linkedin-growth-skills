# Where Each Edit Lives

For the do-this-week list. A fix the user cannot find does not get done, so every
item names the control to click.

**Last verified: November 2026, desktop web.** LinkedIn moves controls without
notice. "Seen" means the control was observed on a live profile on that date.
"Reported" means it is the commonly documented path and was not re-checked. If a
path does not match what the user sees, describe the destination ("the edit form
for the intro card") instead of insisting on the path.

| Edit | Where, on the user's own profile | Checked |
|---|---|---|
| Headline, location, education shown in the intro | Pencil icon on the intro card, below the banner on the right | Seen |
| Custom button (Premium) | The same intro form, further down | Reported |
| Banner | Pencil icon on the banner | Seen |
| Photo | Click the photo | Reported |
| About | Pencil icon on the About card | Reported |
| Featured: add | Plus icon on the Featured card, then choose a post, link, or media | Reported |
| Featured: reorder or remove | Open the Featured card's full list, then use the control on each item | Seen |
| Experience | Pencil icon on the Experience card, then the pencil on the entry | Reported |
| Skills order | Pencil icon on the Skills card, then Reorder in the menu | Reported |
| Services | "View my services" under the name, then edit | Seen |
| Ask for a recommendation | The Recommendations card, then the plus icon | Reported |
| Custom URL | "Public profile & URL" at the top of the right-hand column | Seen |
| Contact info and website | "Contact info" next to the location, then "Edit contact info" | Seen |
| Follow as the primary button | Settings, then Visibility, then Followers | Reported |
| A section that does not exist yet | "Add section" under the name | Seen |

## Rules

- One control per step. "Click the pencil on the About card, paste the draft, save"
  is a step. "Update your About" is not.
- The agent does not make the edits. It reads; the user changes their own profile.
- The mobile app lays these out differently. If the user is on a phone, say the
  paths are for desktop and name the section to look for.
