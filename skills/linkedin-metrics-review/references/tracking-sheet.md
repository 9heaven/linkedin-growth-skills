# Weekly Tracking Sheet

Twelve columns. If it takes more than 10 minutes on a Friday, it gets abandoned,
and an abandoned sheet teaches nothing.

## Sheet 1 — Weekly rollup

| Column | What goes in it |
|---|---|
| Week ending | Date |
| Posts published | Count |
| Comments made | Count of substantive comments on others' posts |
| Impressions | Sum for the week |
| Profile views | From profile analytics |
| Search appearances | Weekly number |
| New followers | Net |
| Inbound DMs | Conversations started, not notifications |
| Calls booked | Count |
| Proposals sent | Count |
| Clients closed | Count and value |
| One change made | The single variable you changed this week |

The last column is what makes the sheet useful. Without it you have data and no
learning.

## Sheet 2 — Per-post log

| Column | What goes in it |
|---|---|
| Date | |
| Pillar | Authority / proof / teaching / personal |
| Format | Text, image, carousel, video, poll |
| Hook | First line, pasted |
| Impressions | At 48 hours |
| Reactions | At 48 hours |
| Comments | At 48 hours |
| Reposts + saves | The signals that matter |
| Profile views attributed | Spike on the day of the post |
| DMs attributed | Any conversation that named the post |

Read this monthly by sorting on DMs attributed, then on saves. Ignore the
reactions column when deciding what to write more of.

## Sheet 3 — Audience check, monthly

Paste the top 10 job titles and top 10 industries from follower demographics,
next to the target ICP. One line of verdict: converging or drifting.

## Setup

Google Sheets or Excel is fine. Company page analytics export to XLSX; personal
profile has no export, so numbers are entered by hand. That is a feature — it
takes five minutes and it forces you to look at them.

## Reading the sheet

- Compare to the same account four weeks ago, never to another creator.
- Look at 4-week rolling averages. Single weeks are noise.
- If DMs are flat for 6 weeks while impressions climb, the audience is wrong.
  That is the finding, and it outranks everything else in the sheet.
