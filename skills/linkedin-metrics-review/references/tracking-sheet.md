# Weekly Tracking Sheet

Twelve columns. If it takes more than 10 minutes on a Friday it gets abandoned, and
an abandoned sheet teaches nothing.

## Sheet 1: Weekly rollup

| Column | What goes in it |
|---|---|
| Week ending | Date |
| Posts published | Count |
| Comments made | Count of substantive comments on other people's posts |
| Impressions | Sum for the week |
| Profile views | From profile analytics |
| Search appearances | The number for the period LinkedIn shows |
| New followers | Net |
| Inbound DMs | Conversations started, not notifications |
| Calls booked | Count |
| Proposals sent | Count |
| Clients closed | Count and value |
| One change made | The single variable you changed this week |

The last column is what makes the sheet useful. Without it you have data and no
learning.

## Sheet 2: Per-post log

| Column | What goes in it |
|---|---|
| Date | |
| Pillar | Authority / proof / teaching / personal |
| Format | Text, image, carousel, video, poll |
| Hook | First line, pasted |
| Impressions | At 48 hours |
| Reactions | At 48 hours |
| Comments | At 48 hours |
| Reposts | At 48 hours |
| Engagement rate | (reactions + comments + reposts) / impressions x 100, at 48 hours |
| Saves and sends | At 7 days: saves keep arriving after the first two days |
| Profile views attributed | The spike on the day of the post |
| DMs attributed | Any conversation that named the post |

Read this monthly by sorting on DMs attributed, then on saves. Ignore the reactions
column when deciding what to write more of.

## Sheet 3: Audience check, monthly

Paste the top 10 job titles and top 10 industries from follower demographics, next
to the target buyer. One line of verdict: converging or drifting.

## Setup

Google Sheets or Excel is fine. Company page analytics export to a spreadsheet;
personal numbers are mostly entered by hand. That is a feature: it takes five
minutes and it forces you to look at them.

## Reading the sheet

- Compare with the same account four weeks ago, never with another creator.
- Look at 4-week rolling averages. Single weeks are noise.
- If DMs are flat for 6 weeks while impressions climb, the audience is wrong. That is
  the finding, and it outranks everything else in the sheet.
